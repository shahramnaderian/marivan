# اپلیکیشن اوقات شرعی مریوان ۱۴۰۵

اپلیکیشن فارسی و راست‌چین برای نمایش اوقات روزانه و تنظیم هشدارهای مستقل در مریوان؛ قابل نصب به‌صورت وب‌اپ (PWA) و دارای مسیر ساخت نسخه اندروید (APK) با Capacitor.

## پوشش داده‌های اوقات شرعی
- داده‌های اکسل ۸ ماه در برنامه ادغام شده‌اند: آذر تا اسفند ۱۴۰۵ و تیر تا مهر ۱۴۰۶.
- برای جلوگیری از خطای اعلان، هشدار نماز عشا فعلاً غیرفعال است؛ مقدار ستون «نماز عشا» در فایل‌های اکسل با «نماز ظهر» یکسان ثبت شده و باید از منبع اصلی بررسی شود.
- ساعت‌ها عیناً از فایل‌های اکسل وارد شده‌اند؛ پیش از اتکا به اعلان‌ها، با جدول رسمی تطبیق دهید.

## امکانات
- نمایش ساعت و انتخاب روزهای جدول از آبان ۱۴۰۵ تا مهر ۱۴۰۶ (ماه‌های دارای داده)
- نمایش ۱۰ ستون جدول اوقات روز و شب
- تنظیم جداگانه ساعت و روشن/خاموش‌کردن هشدار هر رویداد
- انتخاب زنگ داخلی، فایل صوتی اذان از گوشی یا حالت بی‌صدا
- تعیین زمان یادآوری پیش از رویداد
- ذخیره تنظیمات در گوشی و پشتیبان‌گیری/بازیابی JSON
- استفاده آفلاین پس از بارگذاری اولیه
- زمان‌بندی اعلان‌های محلی اندروید برای ۳۰ روز آینده با مجوز اعلان و هشدار دقیق

## اجرای نسخه وب
محتوای مخزن را روی GitHub Pages منتشر کنید و نشانی Pages را با Chrome اندروید باز کنید. از منوی مرورگر گزینه Install app / Add to Home screen را بزنید.

## ساخت APK اندروید
در مخزن، از مسیر **Actions → Build Android APK → Run workflow** فرایند ساخت را اجرا کنید. پس از موفقیت، فایل APK در بخش Artifacts همان اجرای workflow با نام `marivan-android-debug-apk` قرار می‌گیرد.

برای ساخت محلی نیز به Node.js 22، Java 21 و Android SDK نیاز است:

```bash
npm ci
npx cap add android
npm run android:debug
```

اگر پوشه `android` از قبل وجود دارد، دستور `npx cap add android` را اجرا نکنید.

## هشدار مهم درباره دقت داده‌ها
جدول اصلی ارسالی شامل ۵ صفحه و ۱۴۹ روز (آبان تا اسفند ۱۴۰۵) است. داده‌های فعلی در برنامه از استخراج دیجیتال جدول تهیه شده‌اند، اما بخشی از خانه‌ها در نسخه OCR اولیه مبهم یا نیازمند تطبیق با تصویر PDF هستند. بنابراین پیش از اتکا به هشدارهای نماز، ساعت‌های هر روز را با نسخه تصویری جدول اصلی کنترل کنید. خانه‌های خالی را عمداً خالی گذاشته‌ایم؛ برای جلوگیری از هشدار اشتباه، ساعت تأییدنشده را حدس نزنید.

## مجوزهای اندروید
برای اعلان‌ها، مجوز Notifications را بدهید. اگر اندروید درخواست کرد، دسترسی Alarms & reminders / Exact alarms را نیز فعال کنید. محدودیت‌های صرفه‌جویی باتری برخی سازندگان ممکن است بر تحویل اعلان اثر بگذارد.

## ساختار پروژه
- `index.html`: رابط کاربری و داده‌های جدول
- `native-alarms.js`: اتصال زمان‌بندی هشدارها به اعلان محلی اندروید
- `scripts/prepare-web.mjs`: آماده‌سازی فایل‌های وب برای Capacitor
- `scripts/patch-android.mjs`: افزودن مجوز هشدار دقیق
- `.github/workflows/android.yml`: ساخت خودکار APK با push و اجرای دستی
- `.github/workflows/android-apk.yml`: ساخت دستی APK
