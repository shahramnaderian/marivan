| `Marīvān-1406-03.csv` | خردادماه |

## نحوه استفاده
فایل‌های CSV را می‌توانید مستقیماً در Excel، Google Sheets یا LibreOffice باز کنید.

اگر به فایل‌های اصلی `.xlsx` نیاز دارید، از نسخه CSV استفاده کنید یا بگویید تا دوباره اضافه کنم.
